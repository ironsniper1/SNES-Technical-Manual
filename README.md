This is a work in progress translation of the Playtronic SNES service manual (manual Técnico). The original manual in Brazilian Portuguese can be found [here](https://wiki.console5.com/wiki/File:Manual_Technico_do_Super_NES_Rev_01-94.pdf)

Due to a lack of official service documentation for the SNES, I began translating this service manual into English. This proved to be quite the challenge as the original scan is pretty rough, and I do not speak Portuguese. I would estimate the translation is 50% complete, but this has already taken many more hours than I had planned, and I no longer have time to dedicate to completing the translation.

Everything up to page 42 of this document has been reformatted and roughly checked for accuracy against the original manual. But that is not to say everything before page 42 will not contain errors or poor grammar, either due to the original containing those errors, or a mistranslation by myself (or more specifically whatever I used to OCR the original and translate). I did all this a couple of years ago, so I don’t remember exactly what I used.

I would recommend downloading the PDF format, unless you want to continue the translation work in which case a DOCX file is also available.

For the most part all the valuable information has been translated, that includes the service procedure for the console itself, and the burn-in test cartridge fault table (p.21). The remaining stuff that I haven’t touched from page 42 onwards relates to troubleshooting accessories, IC handling and a glossary.

Keep in mind text from the original images has not been translated, and some may be missing due to their poor quality. Basically, if they looked like shit and didn’t offer anything useful, they were not transferred over to this document.

As this manual was written around 1994 it mainly refers to the SHVC revision with only a brief mention of the GPM revision.

If anyone wants to complete the translation, check it for errors, make amendments, add a proper index etc. then please do. Just be sure to make it available somewhere for everyone else.
